# Autenticación React Native

App de ejemplo que implementa **autenticación completa** en React Native con TypeScript:
registro, login, persistencia de sesión y rutas protegidas.

## Stack

- React Native + Expo
- TypeScript
- Persistencia segura del token

## Cómo correrlo

```bash
npm install
npx expo start
```

## Qué demuestra

- Flujo de autenticación de punta a punta
- Manejo de estado de sesión
- TypeScript en React Native
